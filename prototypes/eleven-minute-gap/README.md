# 11분의 공백 · 독립 HTML 검수본

추리형 재판 게임 `11분의 공백`의 단일 파일 HTML 검수본이다.

- `index.html` 하나에 이미지(WebP, base64)와 코드가 모두 들어 있어 인터넷 연결 없이 브라우저에서 바로 열 수 있다.
- 이 폴더는 Next.js 앱의 `app/`·`public/` 밖에 있으므로 빌드·배포 대상이 아니다. 공식 도메인이나 Preview에 노출되지 않는다.
- 저장은 브라우저 `localStorage`의 `ttanjitmoa-design-review-20261014-v1*` 키를 사용한다.

## 확인 방법

```bash
# 파일을 직접 열거나
open prototypes/eleven-minute-gap/index.html
# 정적 서버로 연다
npx serve prototypes/eleven-minute-gap
```

하단 검수 바의 1–8 화면 이동, `원본 시안`, `검수 메모`로 화면별 검수를 진행한다.

## 시각 연출 레이어 (2026-10-14)

`index.html`의 `<style>` 끝과 `applyPrefs();render();` 바로 앞에 `Visual layer` 블록을 추가했다. `render()` 끝에서 `decorate()`를 한 번 호출하는 것 외에는 기존 게임 로직·저장 키·상태 구조를 바꾸지 않는다. `decorate()`는 `S`를 읽기만 한다.

| 영역 | 내용 |
|---|---|
| 화자 표시 | 대사창 이름표에 인물 초상(기존 일러스트에서 잘라 씀)·이니셜 메달·기록 아이콘, 진영별 색(재판부·검찰·변호·피고인·피해자·증인·기록) |
| 카메라 | 법정 전경 장면에서 발언자 쪽으로 컷 후 천천히 밀기(검사 오른쪽, 피고인·변호인 왼쪽, 증인 증언대), 그 외 장면은 느린 드리프트 |
| 대사 | 타자 효과(장면 클릭으로 즉시 완성), 다음 표시 ▼, 무대 지시문은 대사 후 표시. 전체 문장은 화면낭독기용으로 DOM에 유지 |
| 장 전환 | 새 장 첫 장면에 장 제목 카드와 레터박스 |
| 서막 | 22:14–22:25 CCTV 4대 NO SIGNAL 모니터 벽과 기록 타임라인, 119 녹취 재생 파형 |
| 증거 영상 | REC 표시, 비네트·노이즈, 블랙박스 모니터 녹화등 |
| 상태 피드백 | 증거 확보·모순 발견·시각 보정 확정·결정적 장면 제시·판결 선고 순간에 도장/의사봉 연출, 오답 안내는 경고 박스와 흔들림 |
| 진행 표시 | 헤더의 `핵심 증거 n/4` 표시(원본·대조·시각·행위), 누르면 사건 기록 |
| 기타 | 법정 문 목재·문틈 빛·저울 문장, 사건번호 탭·공판 도장, 주차 도면 조명·선택 링·회신 도장, 블랙박스 LED 시계, 정정 전 진술 취소선, 판결문 인장과 평가 배지 |

- 모션 줄이기(OS 설정 또는 게임 설정)에서는 타자 효과·장 카드·카메라 이동·흔들림을 끄고 피드백은 정적으로 잠시 표시한다.
- 시작 시 내장 이미지를 Blob URL로 한 번 변환해, 렌더마다 수백 KB의 base64 문자열을 다시 넣지 않는다(증거 비교 화면 기준 렌더 HTML 814KB → 4KB).
- Google Fonts `Noto Serif KR`를 불러오되, 오프라인에서는 기존 로컬 글꼴로 대체된다.
