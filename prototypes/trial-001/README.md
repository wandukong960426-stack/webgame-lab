# 재판 게임 체험판 · 사건 001 「11분의 공백」

`index.html` 한 파일로 동작하는 독립 프로토타입이다. Next.js 앱에 연결되지 않으며 `prototypes/`는 사이트에서 서비스되지 않는다. 브라우저에서 파일을 직접 열어 플레이한다.

- 출처: 사용자가 전달한 「심리 강화판 v4」 HTML
- 현재 판: v6 (v5 재미 보강 + v6 사용성 개선)
- 배포 상태: 구현됨 · 공식 도메인과 Sites 운영본에는 반영되지 않음

## v6에서 바뀐 것 · 사용성

| 영역 | 내용 |
|---|---|
| 증거 파일 | 처음부터 14개 분류 탭(10개 잠김)을 나열하던 방식을 없앰. 공판 장면에서 자료가 접수될 때마다 증1, 증2… 번호를 붙여 하나씩 쌓고, 안 읽은 자료에는 「새 자료」 표시를 붙임. 자료는 해당 장면에 맞춰 나눠 접수됨(CCTV 8번째, 출입 기록 9번째, 혈흔 감정서 13번째, 119 신고 14번째 장면 등) |
| 접수 이벤트 | 자료가 도착한 장면에 「증거 접수」 카드와 알림을 띄우고, 「열람하기」로 바로 엶. 자료 화면 하단의 「← 공판으로 돌아가기」를 누르면 남은 결정 위치로 스크롤됨 |
| 다음 버튼 | 화면 아래에 고정해 스크롤 없이 누를 수 있음. 쟁점·잠정 판단·조사·대면이 남으면 버튼이 「위 쟁점에 근거를 제시하세요 ↑」처럼 바뀌고, 누르면 해당 위치로 이동함 |
| 자료 고르기 | 쟁점·잠정 판단·피고인 대면에서 드롭다운 대신 요약이 보이는 자료 카드로 고름. 열람한 자료가 없으면 이유를 알려 주고, 안 읽은 자료의 열람 버튼을 함께 보여 줌 |
| 용어 | 반박·보강·입증 범위 제한 버튼에 한 줄 풀이를 붙이고, 도움말에 주문·양형·집행유예 풀이를 추가함 |
| 모바일 | 가로 메뉴 줄을 없애고 하단 「증거 파일」 탭(새 자료 개수 표시)으로 통합함. 도움말에 「처음부터 다시」와 법률·양형기준을 넣음. 법정 사진을 줄이고 장 선택 줄을 숨김. 판결문 탭 제목이 상단바에 가리지 않게 함 |
| 가독성 | 보조 글자색을 #73736f(대비 4.19:1)에서 #5f5d58(5.06:1 이상)로 바꿈. 10~11px 글자를 12px로 올림. 터치 화면에서 버튼 높이를 44px 이상으로 맞춤 |
| 화면 낭독기 | 가운데 영역 전체를 다시 읽던 변경 알림 영역을 없애고, 자료 접수와 결정 결과는 알림 메시지로 전달함 |

## v5에서 바뀐 것

| 영역 | 내용 |
|---|---|
| 쟁점 난이도 | 기록이 그대로 뒷받침하는 주장(「6분은 기록에 있는가」, 정답은 `보강`)을 추가해 7개 쟁점으로 늘림. 쟁점에서 정답 자료 탭으로 바로 가는 버튼을 없앰. 진료기록 쟁점은 진료 기록 장면(15번째)으로 옮기고 피해자 진술을 출처로 지적하는 답도 인정함 |
| 문서 | 증거 문서 안에 적혀 있던 "이 자료로는 무엇을 알 수 없다"는 결론 문장을 걷어내고 사실만 남김. 판단 도움은 장면의 접힌 힌트에 그대로 둠 |
| 휴정 | 단서 보기, 판단 재검토, 피고인 대면 재시도에 쓰는 자원. 기본 3회, 고난도 1회 |
| 영상 검증 | 연속 구간을 프레임 단위로 넘기는 블랙박스 화면(위치 도해). 5개 프레임을 모두 확인해야 원본 검토를 마칠 수 있고, 결정적 장면을 지적할 수 있음. 보정 시각이 화면에 함께 표시됨 |
| 피고인 대면 | 24번째 장면에서 확보한 기록을 피고인에게 제시함. 22:20:10 장면을 제시하면 자백하고, 22:19:50 장면은 진술을 흔듦. 자백하면 변호인 최종 의견, 최후진술, 양형 사정(공판 중 자백), 피해자 측 반응, 후일담이 바뀜 |
| 11분 복원 | 심증 보드 맨 위에 22:12~22:28 시간표를 두고, 확인한 기록으로 빈 칸을 채움. 시계 보정값이 두 기준점과 맞는지도 표시함 |
| 결과 | 진상 일치 × 결정적 기록 검토의 두 축으로 칭호 4종을 줌. 결과 카드 PNG 저장과 결과 문구 공유를 지원함. 칭호와 발견한 경로는 브라우저에 누적됨 |
| 연출 | 시작할 때 NO RECORD 화면과 119 녹취로 여는 오프닝(건너뛰기 가능), 화자 배지, 대사 타자 효과(클릭하면 바로 완성되고 동작 줄이기 설정을 따름), 효과음(기본 꺼짐) |
| 첫인상 | 4번째 장면에서 첫인상을 기록하고 복기에서 최종 판결과 비교함 |
| 고난도 | 시작 화면에서 선택. 판단 도움과 단서가 숨겨지고 휴정은 1회 |
| 용량 | 내장 이미지를 PNG에서 WebP로 바꿔 파일 크기를 5.7MB에서 약 0.48MB로 줄임 |

진상(`CASE_TRUTH`), 법률·양형 안내, 판결문 작성 흐름, 후일담 4갈래는 그대로 유지했다. v4 저장 기록은 v5로 이어서 불러온다(같은 저장 키 `ttanjitmoa-court-001-v1`). 칭호 기록은 별도 키 `ttanjitmoa-court-001-prefs`에 저장한다.

## 구조 메모

기존 파일처럼 확장 블록이 앞 블록의 함수를 감싸는 방식이다. `// v5:` 주석 아래 블록이 `ensurePlay`, `renderCourt`, `renderCenter`, `renderVideo`, `renderBoard`, `showTruth`, `showDebrief`, `advanceCourt` 등을 감싼다. `// v6:` 블록은 증거 접수 목록 `EVIDENCE`(자료별 접수 장면)를 기준으로 사이드바·증거 파일·자료 고르기·다음 버튼 상태를 다시 그린다. 자료와 문구를 고칠 때는 앞쪽 원본 데이터(`STAGES`, `ISSUES`, `SUPPLEMENTS`)를, 접수 시점을 바꿀 때는 `EVIDENCE`를, 새 상호작용을 고칠 때는 v5·v6 블록을 수정한다.

진상은 여전히 소스에 평문으로 들어 있다. 사이트에 올린다면 진상과 블랙박스 프레임 문구를 선고 뒤에 불러오는 방식이 필요하다.

## 검증

Headless Chromium으로 다음 세 경로를 끝까지 진행했다(데스크톱 1440×900, 모바일 390×844).

1. 목격자 경로 → 원본 검토 → 피고인 자백 → 유죄·집행유예 → 진상 → 복기 → 후일담 → 결과 카드 저장
2. 고난도 · 영상 미확보 → 무죄 → 「의심은 피고인의 이익으로」 칭호
3. v4 원본으로 만든 저장을 v5에서 이어하기

v6 기준 모든 단언(127개)이 통과했고 페이지 오류와 콘솔 오류는 없었다.

32개 장면 측정(v5 → v6, 모바일 390×844):

| 항목 | v5 | v6 |
|---|---|---|
| 스크롤해야 「다음」이 보이는 장면 | 32 | 0 |
| 대사 상자가 첫 화면 밖인 장면 | 22 | 0 |
| 막혔는데 버튼이 평소와 같은 장면 | 10 | 0 |
| 대비 4.5:1 미만 글자 종류(쟁점·보드·판결문 화면) | 24 | 0 |
| 44px 미만 터치 대상 | 28 | 0 |

실제 휴대폰 기기와 스크린리더는 확인하지 않았다.
