## 결론

**이번 작업에서 Sites 운영본(`ttanjitmoa` 프로젝트, `https://ttanjitmoa.com`)의 원본 소스를 확보하지 못했다.**
따라서 원본 소스 ZIP, 원본 버전·커밋 식별자, 운영본 기준 설치·빌드 문서는 제공하지 않는다.
webgame-lab의 Next.js 코드나 공개 페이지 수집본을 대신 제공하지 않았다.

원본은 ChatGPT Sites 플랫폼 내부에 있으며, 그 플랫폼 계정에서만 내보낼 수 있다. 아래 절차를 Sites 접근 권한이 있는 쪽(사용자 또는 ChatGPT/Codex)이 수행해야 한다.

## Sites 접근 권한자가 수행할 내보내기 절차

사이트 수정·재배포·도메인 변경 없이 **읽기/내보내기만** 수행한다.

1. Sites 프로젝트 `ttanjitmoa`에서 공식 도메인에 연결된 **현재 활성 배포**를 연다. 미리보기·초안이 아닌지 확인한다.
2. 그 배포의 버전(배포 ID·버전 번호·배포 시각)과 연결된 원본 리비전(커밋 해시 또는 플랫폼 스냅샷 ID)을 기록한다.
3. 해당 리비전의 전체 소스를 내보낸다. 플랫폼에 Git 연동이 있으면 새 비공개 저장소(예: `ttanjitmoa-sites-source`)로 푸시하는 방식을 우선한다. 없으면 ZIP으로 내보낸다.
4. 포함 확인: 프런트엔드, 서버/Worker/함수 코드, 게임 로직, 스토리·방탈출·도전·전술 데이터, 번역 파일, 이미지·음원, 패키지 매니페스트와 잠금 파일, 빌드·배포 설정, 테스트.
5. 제외: 비밀번호, API 비밀키, 토큰, 실제 이용자 데이터(대전 기록, 저장 데이터, 통계 원본, 문의 내용), DB 덤프. 플랫폼 설정에 있는 비밀값은 **이름만** `.env.example`에 적는다.
6. 저장소·ZIP 루트에 아래 `SOURCE_MANIFEST.md`를 채워 넣는다.
7. 비밀값 검사 후 전달한다. 예: `gitleaks detect --no-git -s <폴더>` 또는 GitHub 비밀 스캐닝.
8. 전달 방법: (권장) 새 비공개 GitHub 저장소를 만들어 Claude 세션에 추가 / 또는 Google Drive에 ZIP 업로드 후 파일명을 알려준다. webgame-lab `main`에 직접 섞지 않는다.

전달되면 Claude가 원본을 내려받아 실제로 설치·빌드·테스트를 실행하고, 결과를 바탕으로 운영 문서와 `docs/SITES_PARITY.md`를 갱신한다.
