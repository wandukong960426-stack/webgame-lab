# Sites 운영본 ↔ GitHub 버전 기능 차이

확인일: 2026-09-16

이 문서는 공식 도메인 `https://ttanjitmoa.com`에서 관찰한 운영 화면과 이 저장소 `main`의 코드를 비교한 초기 인벤토리다. 운영 화면에서 문구가 보인다는 것과 실제 구현을 코드로 검증했다는 것은 구분한다.

## 요약

- 공식 도메인은 현재 ChatGPT Sites 계열 운영본을 제공한다.
- 이 GitHub 저장소는 별도의 Next.js 6종 게임 버전이다.
- 두 버전은 기능·저장 방식·URL 수·관리 구조가 다르다.
- 기능 이관 결정을 끝내기 전에는 GitHub 버전으로 공식 도메인을 덮어쓰지 않는다.

## 초기 비교표

| 추가 게임 | 미니 스도쿠, 지뢰찾기 | 없음 | 이관 결정 필요 |

| 배포 식별 | GitHub 커밋 식별 엔드포인트 없음 | `/api/release` 추가 | 전환 후 검증 기준 |

## 공식 도메인에서 확인한 주요 URL

- `/`
- `/about`
- `/contact`
- `/privacy`
- `/terms`
- `/games/omok/`
- 영문 쿼리 예시: `/games/omok/?lang=en`

공식 도메인 홈에는 `오늘의 도전`, `전술 36문제`, `게임 가이드`, 언어 선택기가 표시된다.

## 이관 원칙

각 기능은 다음 중 하나로 명시적으로 분류한다.

1. **그대로 이관**: 사용자 가치와 검색 가치가 검증됐고 GitHub로 옮긴다.
2. **재설계 후 이관**: 유지하되 데이터 구조·UX·개인정보 처리를 다시 설계한다.
3. **Sites 유지**: 한시적으로 Sites에서만 유지하며 공식 도메인 전환을 보류한다.
4. **폐기**: 중복·저품질·운영 부담 등의 이유와 함께 제거한다.

`완료 보고가 있었다`는 이유만으로 이관 대상 또는 구현 완료로 분류하지 않는다.
