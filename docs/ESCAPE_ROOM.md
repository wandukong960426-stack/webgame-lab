# 3D 방탈출: 별지기의 서재

경로: `/games/escape-room` · 상태: GitHub 전용 신규 게임 (공식 Sites 운영본에는 없음)

사용자 조사 자료(웹 포인트앤클릭형·라이브 방탈출에서 사람들이 좋아하는 요소)를 바탕으로 만든 브라우저 3D 방탈출이다. Unity/Unreal 수준의 표현을 목표로 하되 설치 없이 동작해야 하므로 WebGL(Three.js)로 구현했다.

## 조사 요소 → 구현 대응

| 조사에서 강조된 요소 | 구현 |
|---|---|
| 최소한의 인터페이스, 은은한 배경음, NPC 없음 | 가장자리에만 작은 HUD. 절차적으로 합성한 배경음(패드·바람·종소리). 등장인물 없이 일지·쪽지로만 이야기 전달 |
| 커서 모양 변화로 상호작용 대상 안내 | 마우스를 올리면 커서가 손가락으로 바뀌고 금빛 외곽선과 이름표가 뜸 (OutlinePass) |
| 아트 톤앤매너와 오브젝트 가독성 | 달빛 천문학자 서재 한 가지 톤. 퍼즐 물건은 크고 색·기호로 구분하고, 궤짝 다이얼에는 현재 달 모양을 보여 주는 읽기 창을 둠 |
| 적정 좌절감 | 8단계를 점점 어렵게 배치. 근접 오답(예: `0940`)은 "숫자 자체는 맞다"는 노란 표시로 따로 알려 줌 |
| 다양한 사고 유형 | 탐색(러그), 아이템 사용(서랍), 시각(UV 형광 글씨), 기호 매칭(달 다이얼), 공간(망원경 시야 이동), 순서(책장), 장치(퓨즈), 논리(24시간제 암호) |
| 인터랙티브 소품 | 서랍·궤짝 뚜껑·책·문 애니메이션, 도어락 LCD와 LED, 퓨즈를 끼우면 깜빡이며 켜지는 조명, 물건을 주우면 화면으로 날아오는 연출, 조작마다 효과음 |
| 초반 장식이 후반 단서가 되는 구조 | 첫 화면의 멈춘 벽시계(9:40)와 창밖의 달이 마지막 암호 `2140`의 근거. 처음부터 걸린 성도 액자의 문구가 책장 순서 읽는 법 |
| 부담 없는 힌트 | 💡 "별지기의 메모" 3단계(살짝 → 구체적으로 → 거의 정답). 벌점 없이 횟수만 기록. 진행이 멈추면(여유 120초·도전 90초) 힌트를 권하는 안내만 띄우고 답은 자동으로 보여 주지 않음 |
| 탐정·탐험가 판타지, 스트레스 해소 | 사라진 교수의 조수라는 역할, 탈출 후 에필로그와 등급(전설의 별지기 등) |
| 타이머형과 여유형 선택 | 여유 모드(제한 없음) / 도전 모드(30:00). 시간이 지나도 실패 처리하지 않고 여유 모드로 이어 가기 제공. 일시정지·자동 저장·이어하기 |
| 협동 | 이번 범위에서 제외 (아래 제한사항 참고) |

## 퍼즐 흐름

1. 러그의 들린 모서리 → 황동 열쇠
2. 열쇠로 책상 서랍 → UV 손전등, 관측 일지 1쪽
3. UV로 달의 위상 포스터를 비춤 → ① 초승달 ② 보름달 ③ 하현달
4. 궤짝 다이얼을 순서대로 맞춤 → 접안렌즈
5. 렌즈를 망원경에 끼우고 하늘을 끌어 색깔 별자리를 찾음
6. 가장 밝은 파란 별부터 선을 따라 책을 당김 (파랑 → 빨강 → 보라 → 금색 → 초록) → 비밀 칸의 퓨즈와 일지 마지막 장
7. 퓨즈를 문 옆 퓨즈함에 끼움 → 방에 불이 들어오고 도어락이 켜짐
8. 벽시계 9:40 + 창밖의 밤 + "별지기의 시계는 스물네 시간을 센다" → `2140`

## 구조

| 파일 | 역할 |
|---|---|
| `lib/escape-room/puzzle.ts` | 렌더링과 분리된 순수 규칙(리듀서), 힌트, 핫스팟 정의, 저장 데이터 검증 |
| `components/escape-room/scene.ts` | Three.js 장면: 절차적 모델링, PBR 재질, 달빛 그림자, 볼류메트릭 광선, 먼지, 블룸·외곽선·비네트 후처리, 레이캐스트, 카메라 연출, 적응형 품질 |
| `components/escape-room/textures.ts` | 외부 이미지 없이 캔버스로 그리는 나뭇결·마루·벽지·러그·포스터·성도·시계·LCD 텍스처 |
| `components/escape-room/audio.ts` | Web Audio 배경음과 효과음 합성 |
| `components/escape-room/TelescopeView.tsx` | 망원경 접안렌즈 시야(2D 캔버스) |
| `app/games/escape-room/page.tsx` | 게임 화면, HUD, 오버레이, 자동 저장, 키보드·접근성 목록 |

- 외부 모델·이미지·음원 파일이 없어 추가 네트워크 요청이 없다.
- Three.js 장면 모듈은 동적 import로 분리해 다른 페이지 번들에 포함되지 않는다.

## 품질·안정성

- 품질: `자동 / 고화질 / 저사양`. 자동은 터치 기기나 코어 4개 이하에서 저사양으로 시작하고, 고화질에서 FPS가 32 미만이면 저사양으로, 저사양에서도 22 미만이면 해상도를 더 낮춘다.
- WebGL 2를 쓸 수 없으면 텍스트 탐색 모드로 전환해 목록으로 끝까지 진행할 수 있다. 그래픽 컨텍스트가 유실되면 진행을 유지한 채 "3D 다시 불러오기"를 제공한다.
- 접근성: 사이드 패널(모바일 전체화면에서는 조작 서랍)에 장소 이동과 조사 목록, 도어락 숫자판을 버튼으로 제공. 상태 문구는 `aria-live`로 안내. `prefers-reduced-motion`이면 카메라 이동과 CSS 애니메이션을 최소화.
- 조작: 드래그·스와이프로 둘러보기, 클릭·탭으로 조사, 우클릭·Esc로 뒤로, 방향키로 둘러보기, 도어락 화면에서 숫자 키 입력, H로 힌트.
- 저장: `lib/game-progress.ts`의 공용 자동 저장을 사용해 홈의 "하던 판 이어하기"에 표시된다.

## 새 의존성

- `three`(런타임), `@types/three`(개발). 기존 구현으로는 실시간 3D 렌더링, PBR 조명, 그림자, 후처리를 제공할 수 없어 추가했다. 방탈출 페이지에서만 동적으로 불러온다.

## 제한사항과 후속 과제

- 협동(여러 명이 정보를 나눠 푸는) 모드는 서버 동기화가 필요해 이번 범위에서 제외했다.
- 다국어는 다른 게임과 마찬가지로 한국어만 지원한다.
- 자동 검증 환경의 소프트웨어 WebGL(SwiftShader)에서만 전 구간을 확인했다. 실제 모바일 GPU(iOS Safari, 안드로이드 크롬)의 프레임 속도와 발열은 실기기 확인이 필요하다.
- 에피소드 2(옥상 천문대)는 엔딩의 예고만 있고 구현되지 않았다.
