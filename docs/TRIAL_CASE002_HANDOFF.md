## 4. 저장 호환을 정확히 이해할 것

### v2 → v2.4

- `caseId: '002'`, `schema: 2`의 정상 저장은 이어하기로 복원한다.
- 이름, 현재 공판 단계·장면, 확보·열람·인용한 증거, 메모, 해결 여부, 조사 선택, 판결문 초안, 대조 중 선택, 직접 질문·답변 초안과 취지 등을 검증 후 복원한다.
- 새로 추가된 필드가 없으면 기본값으로 채운다.
- 주문·유무죄·형량이 모순된 완료 기록은 완료로 인정하지 않고 판결문 초안 단계로 복구한다.
- 발언이 많아도 핵심 공판 기록을 별도로 보존한다. 선택형 추가 발언은 최근 기록 한도가 있어 모든 대화를 무제한 영구 저장하는 것은 아니다.

### v1 → v2.4

- 현재 v2 저장이 없을 때 `caseId: '002'`, `schema: 1`의 기존 기록을 확인한다.
- v1 원본은 지우지 않는다. 이름·메모·판결문 초안을 가져온다.
- 개정된 증거와 예전 판단이 섞이지 않도록 현장 검증 진입 지점인 `scene: 6`부터 다시 심리한다. 초기 자료 3개를 열고 이전 해결·조사·완료 판정을 초기화한다.
- 시작 화면에 ‘개정된 증거부터 이어하기’와 이 복구 방식에 대한 안내가 표시된다.
- 따라서 ‘모든 구버전에서 정확히 중단한 화면을 그대로 이어간다’고 설명하면 안 된다.

## 5. 회원·칭호·커뮤니티에서 유지할 계약

- 비회원도 플레이 가능하다. 적립은 유효한 회원 플레이 티켓으로 선고까지 완료한 경우에 처리한다.
- 사건 001과 사건 002는 서로 다른 클리어로 집계한다. 같은 사건 재플레이나 완료 요청 재전송은 중복 집계하지 않는다.
- 유죄·무죄 또는 정답 여부와 상관없이 재판 완료 여부를 기준으로 한다.
- 이미 끝난 비회원 저장을 로그인 뒤 열기만 해서는 소급 적립하지 않는다.
- 클라이언트가 보내는 칭호 ID·누적 숫자를 신뢰해 승급시키지 않는다.
- 기본 표시는 획득한 최고 판사 칭호를 자동 선택한다. 사용자가 이전 칭호를 직접 선택했거나 숨김을 선택한 경우 그 설정을 존중한다.
- 커뮤니티 글·댓글은 회원 계정에 연결되고 서버가 제공한 칭호만 표시한다. 기존 글도 현재 대표 칭호를 반영한다.
- 기존 회원의 완료 기록과 수동 선택 칭호를 유지한다. 정지·탈퇴 시 배지 처리도 기존 구현대로 유지한다.

이는 게임용 성장 체계다. 이 후보의 정식 재판 카탈로그에는 001·002 두 사건이 있으므로 현재 제공 사건만 반복해서 10개 승급을 달성할 수는 없다. QA의 10/20/30/…/70 경계값은 로컬 시험 데이터로 검사했으며 가짜 사건을 사이트에 게시하지 않았다.

## 6. 서사·이미지 기준

- 4개 장, 본 공판 30장면, 핵심 대조 3개와 선택 재신문 구조를 유지한다.
- 현장 인원은 피해자 이준서·피고인 강태오·증인 문시현, 총 3명이다.
- 고정 진상: 강태오가 공격했고 문시현은 문을 막았다. 증인의 별도 형사책임까지 이 사건 피고인에 대한 선고로 확정하지 않는다.
- 피해자는 사망한 설정이다. 성공적인 판단의 후일담은 유가족의 일상 회복으로 표현하며 피해자가 살아 돌아오는 장면을 넣지 않는다.
- 피고인이 무죄 선고 뒤 숨기는 미소, 증인의 후회, 피해자 가족의 세 달 뒤를 속마음과 행동 묘사로 구분한다.
- 1심 선고를 곧 확정판결로 쓰지 않는다.
- 검사·변호인·피고인·증인·감정인·유가족 6명 초상화는 하나의 3×2 이미지에 있으며 화자 ID에 맞춰 표시한다.
- 대사 중 큰 초상, 발언자 작은 초상, 직접 질문의 응답 초상, 선고 반응·후일담 초상 연결을 검사했다.
- 현재는 정적 초상화다. 장면별 웃음·슬픔 표정 이미지 변경이나 감정 애니메이션은 구현돼 있지 않다.
- 배경은 판사석 시점이다. 검사 좌우 배치에 관한 현실 법정 일반화는 이번 QA의 검증 범위가 아니다.

## 7. 반영한 추가 QA 수정 11항목

1. 직접 질문 응답창에 해당 발언자 초상 추가.
2. 제삼자 행동 설명이 인물의 대사로 섞이던 문장 수정, 대사와 상황 설명 분리.
3. CCTV 프레임을 인용하면 화면만 첫 장면으로 돌아가던 오류 수정.
4. 직접 질문·답변의 쟁점·취지 선택 저장 및 복원.
5. 선택 발언이 많아져도 초기 공판·핵심 증거 기록 보존. 누락된 과거 기록을 현재 대사로 대체하지 않음.
6. 도움말·모달을 닫으면 진행 중 증거 대조 화면이 사라지던 오류 수정.
7. 미확보 증거의 정답 암시가 심증 보드에 먼저 노출되던 문제 수정.
8. 증인·피해자를 선고 대상으로 적은 주문이 피고인 선고로 처리되던 문제 차단.
9. 현장에 제4자가 없었다는 인원 표현 명확화.
10. 좁은 화면에서 숨겨지던 도움말 버튼 복구.
11. 모달 키보드 순환과 닫은 뒤 호출 버튼으로 초점 복귀 보완.

## 10. 후속 작업의 완료 기준

기능·자동 검증을 통과한 이 소스를 출발점으로 사용한다. 이어서 실제 브라우저에서 이름 입력 → 입장 → 질문/답변 → 이전 장면 복귀 → 증거 대조 → 새로고침/이어하기 → 선고 → 후일담 → 다시하기를 검사한다. PC와 모바일의 초상화 잘림·버튼 겹침·스크롤·소프트 키보드·전체화면은 별도로 확인한다. 실제 회원으로 첫 클리어 1회 적립, 동일 사건 재클리어 중복 없음, 커뮤니티 글·댓글 칭호 표시를 확인한다. 검수 중 바뀐 점과 남은 항목을 사용자에게 제시하고, 배포 지시 뒤에만 배포한다.
