## 1. 배경

- **해담FM 98.7**: 1992년 개국한 지역 라디오. 오늘(11월 30일) 자정 송신 종료로 폐국한다.
- **1999년 8월 3일**: 02:05 상곡저수지 방류 통보 팩스 수신. 7월에 허위 팩스가 있었던 탓에 야간 PD 윤서진이 저수지에 확인 전화를 걸었으나 회선 혼잡으로 지연. 경보는 **02:41**에 송출(36분 지연). 은하천 하류 야영장에서 2명 사망.
- 공식 경위서와 편집본은 **02:07 송출**로 기록. 기록 담당 민해수(당시 26세)가 윤 PD 지시·국장 승인으로 감시 녹음을 편집했고, 원본 소거 지시를 어기고 금고 대장에 `HD-L-990803 감시녹음 예비`로 숨겨 두었다.
- 원본 매체: 1/4인치 오픈릴 **10.5인치 금속 릴(NAB), 빨간 리더, 4.75cm/s**, 리더 끝 펀칭 `L-990803`. 편집본: 7인치 플라스틱 릴, 흰 리더(`HD-E-990803`).

## 2. 범인과 해답

- **범인: 윤서진 (편성국장)**
- **수법**: 18:00 리허설 Take 2를 21:45 마지막 인사로 자동 송출하게 해 “생방송 중” 알리바이를 만들고, 그동안 2층 동측 계단 스위치반에서 1층 복도 조명을 끈 뒤 부조정실 예비 카드 #07로 자료실에 들어가 금고를 열었다.
- **은닉**: 지하 반출대기실 선반 C의 **C-4** 운송 상자에서 업체 빈 릴을 빼고 원본을 넣은 뒤 업체 예비 봉인 **S-4478**로 다시 봉인. 빼낸 빈 릴은 원본의 회색 자료 상자(`HD-L-990803`)에 담아 고철 수거함에 버렸다 (찢어진 업체 봉인 S-4474가 붙은 채).
- **동기**: 원본은 경보가 02:41에 나갔다는 사실, 즉 지연과 그 시각을 고쳐 적게 한 일을 드러낸다.
