### 엔진·데이터 검사가 확인하는 것
- 모든 증거·조건·장면 참조가 실제 데이터를 가리킴, 목표마다 3단계 힌트 존재
- 협동 분석 6개가 모두 두 역할의 자료를 요구 (한쪽만으로 결론 1 불가)
- 시각 교차 검증: CCTV 7분 오차, 조명·출입·센서 시각, 택배·통화가 금고 개방 구간을 덮음, 음원 +30초에서만 10/10 일치, 라디에이터 41초 주기, 업체 목록과 다른 상자는 C-4뿐
- **도달 가능성**: 정답 경로를 따라가며 각 분석·결론 제출 전에 필요한 증거가 모두 얻어지는지
- 중간 결론 전에는 2·3막 자료가 열리지 않음 (의미 전환 2회)
- 오답 피드백이 증거 종류를 알려 주되 **정답 선택지 문구를 포함하지 않음**
- 엔딩 장면의 사실 대사는 해당 증거를 확보했을 때만 나옴
- 저장: 왕복, 깨진 JSON 백업, 비객체 값, 선후 관계 재구성, 엉망인 타입, 미래 버전, 원본 체험판 노트 이전, 저장소 차단, 엔딩 재진입, 설정 분리, 경과 시간

### 브라우저 검사가 확인하는 것 (프롬프트 검수 항목 대응)
1. 처음 접하는 흐름: 타이틀 → 플레이 방법 → 모드 선택 → 도입부(키보드 Enter 포함) → 역할 선택 → 1~3막 조사 → 중간 결론 2회 → 최종 보고서 → 대면 → 선택 → 엔딩 완주
2. 오답 경로: J1(근접 오답), J2(다른 기록계), 결론 1(시각 기록 충돌), 음원 대조(0.5초 어긋남), J3(엉뚱한 출처), 결론 2(근거 3개), J4(문 센서만), 상자 C-2 잘못 열기, 최종 보고서 반려 → 모두 안내 후 진행 가능
3. 힌트 3단계와 확인창, 브라우저 뒤로 가기(대화상자 닫힘 → 평면도 복귀), 증거 재열람(엔딩에서도)
4. 2인 모드 역할 넘기기 화면(뒤 화면 가림·취소), 역할별 노트 분리, 검수 모드는 전달 화면 없이 전환
5. 노트에 `<img onerror>` 입력 → 문자열로만 저장, DOM에 삽입되지 않음
6. 새로 고침 후 이어하기·엔딩 다시 보기·수사 화면 재열람, 처음부터 다시(취소/확인)
7. 저장 손상 안내 + `.corrupt` 백업, 앞뒤 안 맞는 진행 복구, 원본 체험판 노트 이전, localStorage 차단 환경
8. **레이아웃**: 360·390·768·1024·1440px에서 타이틀·모드·도입·역할 선택·평면도·장소·증거 대화상자·CCTV·인터뷰·노트·전달 화면·건물 기록·센서·음원·힌트·공동 분석·시간표·사건 보드·음원 비교·선반·최종 보고서·선택·엔딩 — 가로 스크롤 없음, 화면 밖 요소 없음, 터치 영역 32px 미만 없음
9. 콘솔 오류 0건

### 육안 확인 (화면 캡처)
위 화면들의 360px·1440px 캡처를 직접 보고 다음을 고쳤다: 장면 SVG가 레이아웃 클래스와 충돌해 확대되던 문제, 타이틀 제목 크기, 스위치 토글 겹침, 모바일 상단바 두 줄 → 한 줄, 선반 상자 2열, CCTV 화면 크기, 인물 헤드폰 그림, 한국어 조사(“이안로” → “이안으로”).

## 2. 미검증 항목 (검증했다고 주장하지 않음)

- **사람 플레이테스트**: 실제 소요 시간(30~40분은 추정), 난이도, 협동 대화가 자연스럽게 일어나는지, 힌트 단계의 적절성
- 실제 모바일 기기(iOS Safari, Android Chrome)의 터치·스크롤·주소창·뒤로 가기 제스처
- Safari·Firefox 렌더링 (`:has()` 선택자, `<dialog>`, CSS mask 영수증 테두리 등)
- 화면 낭독기(VoiceOver, TalkBack, NVDA) 실사용
- 효과음의 실제 청감과 음량 균형 (자동 검사는 오디오 출력을 듣지 않음)
- 명도 대비 수치 측정 도구 검사 (색은 대비를 고려해 골랐지만 자동 측정은 하지 않음)
- 여러 탭 동시 사용 시나리오의 브라우저별 `storage` 이벤트 동작
- 원격 멀티플레이: 범위에서 제외 (서버 없음)
